Before placing a batch order, confirm the listings you intend to buy are still available. Pass up to 100 listing ids as a comma-separated `ids` parameter; the response gives the live price of every id still available and lists the ids that are gone.

**Authentication required.** Send your key as `Authorization: Bearer csb_pub_...`.

## Query parameters

<ParamField query="ids" type="string" required>
  Comma-separated listing ids, e.g. `itm_8841201,itm_8841340`. **Required.** Maximum 100 ids per request.
</ParamField>

<ParamField query="appId" default="730" type="integer">
  Game the ids belong to: `730` = CS2, `570` = Dota 2, `252490` = Rust. Use the same `appId` you read the ids with from `GET /v1/listings`.
</ParamField>

## Response fields

<ResponseField name="data" type="object" required>
  <Expandable title="data object">
    <ResponseField name="available" type="object" required>
      Map of listing id → its current price in USD. Every id that is still available appears here.
    </ResponseField>
    <ResponseField name="unavailable_ids" type="string[]" required>
      Listing ids that are no longer available.
    </ResponseField>
  </Expandable>
</ResponseField>

## Example request

```bash
curl "https://csboard.com/v1/listings/availability?ids=itm_8841201,itm_8841340,itm_8841999" \
  -H "Authorization: Bearer csb_pub_..."
```

## Example response

```json
{
  "data": {
    "available": {
      "itm_8841201": 14.37,
      "itm_8841340": 12.1
    },
    "unavailable_ids": ["itm_8841999"]
  }
}
```

## Error codes

| HTTP status | Code | Meaning |
|---|---|---|
| 400 | `unsupported_game` | Your key cannot use this `appId`. `supported_app_ids` lists the ones it can. |
| 401 | `missing_api_key` / `invalid_api_key` | Missing or invalid API key. |
| 422 | `invalid_request` | `ids` was omitted, or more than 100 ids were supplied. |
| 429 | `rate_limit_exceeded` | Too many requests. Back off for the `Retry-After` header value. |

<Tip>
  Availability is a point-in-time snapshot. An id reported as available can still sell out before your purchase executes — always send `max_price_usd` and handle `item_unavailable` on the buy call.
</Tip>
