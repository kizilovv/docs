The first step of listing over the API. It returns every CS2 item we have seen in your Steam inventory, one row per copy — `asset_id` tells two copies of the same skin apart. `listable` says whether a copy can be published right now; when it cannot, `reasons` says why. `listed` marks copies that already have a listing.

Pass `operational_asset_id` and `asset_revision` from this response, unchanged, to [`POST /v1/p2p/listings`](/api-reference/post-p2p-listings).

**Authentication required.** Send your key as `Authorization: Bearer csb_pub_...`. Free — any valid key, no balance requirement.

## The inventory read

Publishing needs a current read of your Steam inventory. `inventory_proof` tells you where that stands:

| `inventory_proof.status` | Meaning | What to do |
|---|---|---|
| `ready` | We hold a current read. | List the rows with `listable: true`. |
| `pending` | This call started a new read. | Call again after `retry_after_ms`. |
| `blocked` | We cannot read your inventory. | Fix what `code` names — for example a private inventory or a missing trade URL — and call again. |

## Example request

```bash
curl https://csboard.com/v1/p2p/inventory \
  -H "Authorization: Bearer csb_pub_..."
```

## Error codes

| HTTP status | Code | Meaning |
|---|---|---|
| 401 | `missing_api_key` / `invalid_api_key` | Missing or invalid API key. |
| 403 | `account_banned` | The account is banned. |
| 403 | `ip_not_allowed` | The request came from outside the key's IP allowlist. |
| 429 | `rate_limit_exceeded` | Over your key's per-minute limit. Wait for the `Retry-After` header value. |
| 503 | `p2p_disabled` | The P2P market is switched off right now. |
