Returns your listings that are on sale or in the middle of a sale, newest first. Each one carries `seller_payout_usd` — exactly what a sale credits to your balance, after our commission.

| `status` | Meaning |
|---|---|
| `active` | On sale. You can reprice or remove it. |
| `trade_pending`, `trade_sent`, `verification_hold` | Sold and mid-delivery. It can no longer be changed. |
| `reconciliation_required` | Taken off the shelf because a full read of your inventory no longer contained the item (`needs_resync: true`). Publish it again once it is back. |

**Authentication required.** Send your key as `Authorization: Bearer csb_pub_...`. Free — any valid key, no balance requirement.

## Example request

```bash
curl https://csboard.com/v1/p2p/listings \
  -H "Authorization: Bearer csb_pub_..."
```

## Error codes

| HTTP status | Code | Meaning |
|---|---|---|
| 401 | `missing_api_key` / `invalid_api_key` | Missing or invalid API key. |
| 403 | `account_banned` | The account is banned. |
| 403 | `ip_not_allowed` | The request came from outside the key's IP allowlist. |
| 429 | `rate_limit_exceeded` | Over your key's per-minute limit. Wait for the `Retry-After` header value. |
| 503 | `p2p_disabled` | The P2P market is switched off right now. |
