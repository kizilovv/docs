[Apply for a CSBoard partner API key](https://csboard.com/cs2-skins-api/#apply) through the [CSBoard B2B skins API program](https://csboard.com/cs2-skins-api/). Buying requires separate permission. The API base URL is `https://csboard.com/v1`. Use it to:

- Fetch live buyable listings complete with float values, paint seeds, sticker data, and USD prices.
- Pull a full gzipped price-list snapshot for bulk catalog ingestion and retrieve FX rates for your payment flows.
- [Fulfill a skin withdrawal](/api-reference/post-market-buy) from live supplier listings. Pay from your settled balance and send the items to the player’s Steam trade URL.
- [Accept a skin deposit](/guides/instant-sell) with sell access. Quote the player’s inventory and reconcile the amount credited to your merchant balance.

## Quick start

Grab live listings in a single request — no setup beyond your API key:

```bash
curl https://csboard.com/v1/listings \
  -H "Authorization: Bearer csb_pub_..."
```
