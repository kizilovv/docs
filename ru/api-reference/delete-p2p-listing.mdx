Снимает с продажи один из ваших листингов в статусе `active`. В момент снятия листинг проверяется ещё раз, поэтому проданный секундой раньше будет отклонён, а не отменён из-под покупателя: проданный или продающийся листинг получает `409 listing_not_active`. Повторное снятие того же листинга даёт тот же `409`.

**Требуется аутентификация.** Отправьте ключ как `Authorization: Bearer csb_pub_...`. Учитывается в лимите P2P-записей ключа — 30 запросов в минуту.

## Пример запроса

```bash
curl -X DELETE https://csboard.com/v1/p2p/listings/cm1xq8z4k0003ab12cd34ef56 \
  -H "Authorization: Bearer csb_pub_..."
```

## Пример ответа

```json
{
  "id": "cm1xq8z4k0003ab12cd34ef56",
  "status": "cancelled"
}
```

## Коды ошибок

| HTTP-статус | Код | Значение |
|---|---|---|
| 403 | `listing_owner_mismatch` | Листинг принадлежит другому аккаунту. |
| 403 | `account_banned` / `ip_not_allowed` | Аккаунт заблокирован или запрос пришёл с адреса вне IP-allowlist ключа. |
| 404 | `listing_not_found` | Листинга с таким id нет. |
| 409 | `listing_not_active` | Листинг продан, находится в процессе продажи или уже снят. |
| 429 | `rate_limit_exceeded` | Больше 30 P2P-записей за эту минуту или превышен общий лимит ключа. Подождите время, указанное в заголовке `Retry-After`. |
| 503 | `p2p_disabled` | P2P-маркет сейчас отключён. |
