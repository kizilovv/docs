openapi: "GET /account/sources_off"
---

Возвращает номера поставщиков, выключенных для вашего аккаунта. Листинги этих поставщиков убраны из всего, что вы читаете: листинги, глубина, цены, оба снапшота и поток.

Если мы выключали поставщиков для вашего аккаунта до 22 ноября 2026, они уже в этом списке. Изменить его можно через [`PUT /v1/account/sources_off`](/ru/api-reference/put-account-sources-off).

**Требуется аутентификация.** Передавайте ключ как `Authorization: Bearer csb_pub_...`.

## Пример ответа

```json
{
  "data": {
    "sources_off": [107, 113]
  }
}
```

Пустой массив означает, что включены все поставщики.
