Первый шаг выставления через API. Эндпоинт возвращает все предметы CS2, которые мы видели в вашем инвентаре Steam, — по строке на каждую копию: `asset_id` отличает две копии одного и того же скина. `listable` показывает, можно ли опубликовать копию прямо сейчас; если нельзя, причину объясняет `reasons`. `listed` отмечает копии, у которых уже есть листинг.

Передавайте `operational_asset_id` и `asset_revision` из этого ответа без изменений в [`POST /v1/p2p/listings`](/ru/api-reference/post-p2p-listings).

**Требуется аутентификация.** Отправьте ключ как `Authorization: Bearer csb_pub_...`. Бесплатно — подойдёт любой действующий ключ, требований к балансу нет.

## Чтение инвентаря

Для публикации нужен актуальный снимок вашего инвентаря Steam. Его состояние показывает `inventory_proof`:

| `inventory_proof.status` | Значение | Что делать |
|---|---|---|
| `ready` | Актуальный снимок есть. | Выставляйте строки с `listable: true`. |
| `pending` | Этот вызов запустил новое чтение. | Повторите запрос через `retry_after_ms`. |
| `blocked` | Мы не можем прочитать ваш инвентарь. | Исправьте то, что указано в `code` — например, закрытый инвентарь или отсутствующий trade URL, — и повторите запрос. |

## Пример запроса

```bash
curl https://csboard.com/v1/p2p/inventory \
  -H "Authorization: Bearer csb_pub_..."
```

## Коды ошибок

| HTTP-статус | Код | Значение |
|---|---|---|
| 401 | `missing_api_key` / `invalid_api_key` | Отсутствует или некорректный API-ключ. |
| 403 | `account_banned` | Аккаунт заблокирован. |
| 403 | `ip_not_allowed` | Запрос пришёл с адреса вне IP-allowlist ключа. |
| 429 | `rate_limit_exceeded` | Превышен поминутный лимит вашего ключа. Подождите время, указанное в заголовке `Retry-After`. |
| 503 | `p2p_disabled` | P2P-маркет сейчас отключён. |
