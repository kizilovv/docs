Возвращает ваши листинги, которые выставлены на продажу или находятся в процессе продажи, — от новых к старым. В каждом есть `seller_payout_usd` — ровно та сумма, которую продажа зачислит на ваш баланс после нашей комиссии.

| `status` | Значение |
|---|---|
| `active` | В продаже. Можно изменить цену или снять с продажи. |
| `trade_pending`, `trade_sent`, `verification_hold` | Продан и доставляется. Изменить его уже нельзя. |
| `reconciliation_required` | Снят с витрины, потому что полное чтение инвентаря больше не нашло предмет (`needs_resync: true`). Опубликуйте его заново, когда предмет вернётся. |

**Требуется аутентификация.** Отправьте ключ как `Authorization: Bearer csb_pub_...`. Бесплатно — подойдёт любой действующий ключ, требований к балансу нет.

## Пример запроса

```bash
curl https://csboard.com/v1/p2p/listings \
  -H "Authorization: Bearer csb_pub_..."
```

## Коды ошибок

| HTTP-статус | Код | Значение |
|---|---|---|
| 401 | `missing_api_key` / `invalid_api_key` | Отсутствует или некорректный API-ключ. |
| 403 | `account_banned` | Аккаунт заблокирован. |
| 403 | `ip_not_allowed` | Запрос пришёл с адреса вне IP-allowlist ключа. |
| 429 | `rate_limit_exceeded` | Превышен поминутный лимит вашего ключа. Подождите время, указанное в заголовке `Retry-After`. |
| 503 | `p2p_disabled` | P2P-маркет сейчас отключён. |
