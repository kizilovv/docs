Публичный фид цен отвечает на один вопрос: какая сейчас самая дешёвая цена на CSBoard для каждого предмета? В ответе — один объект, где каждому `market_hash_name`, выставленному на продажу в выбранной игре, сопоставлена его минимальная цена в USD. Ни глубины стакана, ни количества листингов, ни разбивки по износу, ни пагинации.

**API-ключ не нужен.** Не отправляйте заголовок `Authorization`, баланс тоже не требуется. Это эндпоинт для сайтов сравнения цен, таблиц и парсеров, которым нужно одно число на название.

## Что вы получаете

- **Одна игра на запрос.** `appId=730` — CS2 (по умолчанию), `570` — Dota 2, `252490` — Rust.
- **Названия как в Steam.** Фазы CS2 Doppler и Gamma Doppler объединены под базовым названием, которое использует Steam, поэтому `Karambit | Doppler (Factory New)` получает цену самой дешёвой фазы. Каждый ключ совпадает с реальным `market_hash_name` в Steam.
- **Ключи отсортированы, цены округлены до цента.** В фид попадают только названия, у которых есть хотя бы один листинг в продаже.
- **`updatedAt`** — момент, когда ответ был собран.

## Лимиты и свежесть

Фид пересобирается не чаще **раза в минуту** и отдаётся с `Cache-Control: public, max-age=60`. Лимит — **1 запрос в минуту с одного IP-адреса**. Более частый опрос не даст свежих данных — только `429` с заголовком `Retry-After`.

<Note>
  `429` здесь выдаёт лимитер по IP, а не по ключу, поэтому тело ответа — `{ "error": "...", "statusCode": 429 }`, без поля `code`. Ориентируйтесь на HTTP-статус и ждите `Retry-After` секунд.
</Note>

## Пример запроса

```bash
curl "https://csboard.com/v1/public/prices?appId=730"
```

## Пример ответа

```json
{
  "appId": 730,
  "currency": "USD",
  "updatedAt": "2026-10-02T12:00:41.512Z",
  "items": {
    "AK-47 | Redline (Field-Tested)": 11.92,
    "AWP | Asiimov (Field-Tested)": 96.4,
    "Karambit | Doppler (Factory New)": 812.5
  }
}
```

## Коды ошибок

| HTTP-статус | Код | Значение |
|---|---|---|
| 400 | `invalid_param` | `appId` не входит в число игр, которые мы обслуживаем. В `detail` перечислены доступные. |
| 429 | — | Больше одного запроса за минуту с вашего IP. Подождите время, указанное в заголовке `Retry-After`. |

<Tip>
  Нужны разбивка по износу и фазам, количество листингов, фильтры или пагинация? Используйте [`GET /v1/prices`](/ru/api-reference/get-prices) с ключом. Нужен конкретный листинг для покупки? Используйте [`GET /v1/listings`](/ru/api-reference/get-listings) — этот фид индикативный и может отставать до минуты.
</Tip>
