Заменяет список поставщиков, выключенных для вашего аккаунта. Каждый раз отправляйте список целиком: присланные номера выключены, все остальные включены. Пустой массив включает всех обратно.

Изменение действует со следующего запроса. Оно применяется к листингам, глубине, ценам, обоим снапшотам и потоку. Номера берите из [`GET /v1/sources`](/ru/api-reference/get-sources).

<Note>
  Это фильтр того, что вам показывают, а не запрет покупки. Id листинга, отправленный в `POST /v1/orders`, покупается независимо от поставщика.
</Note>

**Требуется аутентификация.** Передавайте ключ как `Authorization: Bearer csb_pub_...`.

## Тело запроса

<ParamField body="sources_off" type="integer[]" required>
  Номера поставщиков, которых нужно выключить. Номер, которого нет в использовании, отклоняется, чтобы опечатка не выключила «ничего» незаметно.
</ParamField>

## После изменения

- **Поток.** Соединение живёт со списком, с которым было открыто. Переподключитесь, чтобы применить новый, и удалите из своей копии листинги выключенных поставщиков: их `gone` не придёт.
- **Снапшоты.** Снапшот листингов собирается под каждый список. Список, которым ещё никто не пользовался, отвечает `202 snapshot_building`, пока файл не готов.

## Пример запроса

```bash
curl -X PUT "https://csboard.com/v1/account/sources_off" \
  -H "Authorization: Bearer csb_pub_..." \
  -H "Content-Type: application/json" \
  -d '{ "sources_off": [107, 113] }'
```

## Пример ответа

```json
{
  "data": {
    "sources_off": [107, 113]
  }
}
```

## Коды ошибок

| HTTP-статус | Код | Значение |
| --- | --- | --- |
| 400 | `invalid_request` | `sources_off` отсутствует, не является массивом целых чисел или содержит номер, которого нет в использовании. |
| 401 | `missing_api_key`, `invalid_api_key` | Ключ отсутствует или недействителен. |
