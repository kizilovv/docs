通过 CSBoard 订单 id 获取单个订单。响应包含完整的逐件商品明细，包括交付状态、退货原因以及 Steam 报价详情。

**需要身份验证。** 请将密钥作为 `Authorization: Bearer csb_pub_...` 发送。

## 路径参数

<ParamField path="id" type="string" required>
  CSBoard 订单 id，例如 `ord_01J9Z3K8Q2`。
</ParamField>

## 响应字段

响应是一个 `Order` 对象，其结构与 [`GET /v1/orders`](/api-reference/get-orders) 中的条目相同：

<ResponseField name="order_id" type="string" required />
<ResponseField name="steam_id" type="string | null" />
<ResponseField name="status" type="string" required>
  可选值：`completed`、`hold`、`delivering`、`pending`、`cancelled`、`failed` 之一。
</ResponseField>
<ResponseField name="custom_id" type="string | null" />
<ResponseField name="currency" type="string" required>
  始终为 `"USD"`。
</ResponseField>
<ResponseField name="charged_total_usd" type="number" required />
<ResponseField name="item_count" type="integer" required />
<ResponseField name="hold_until" type="datetime | null" />
<ResponseField name="delivery_type" type="string">
  `instant` 或 `manual`。`manual` 表示由真人发送交易，最长 12 小时，在此期间订单可能一直处于 `delivering` 且没有交易报价。P2P 挂单始终为 `manual`。
</ResponseField>
<ResponseField name="delivery_deadline_at" type="datetime | null">
  交付截止时间，仅在 `status` 为 `pending` 或 `delivering` 时有值（持有中的订单为 `null`）。如果卖家未能按时交付，订单会被自动取消并退款。参见 [`POST /v1/orders/{id}/cancel`](/zh-Hans/api-reference/post-orders-cancel)。
</ResponseField>
<ResponseField name="fail_reason" type="string | null">
  订单失败的原因，是用于程序分支判断的代码，例如 `recipient_inventory_private` 或 `listing_gone`。仅在 `status` 为 `failed` 或 `cancelled` 时有值。[代码列表](/zh-Hans/api-reference/get-orders#fail-reasons) 可能会扩充——遇到不认识的值时请按 `unavailable` 处理。
</ResponseField>
<ResponseField name="fail_side" type="string | null">
  需要采取行动的一方：`recipient`、`seller`、`buyer` 或 `market`。仅在 `status` 为 `failed` 或 `cancelled` 时有值。
</ResponseField>
<ResponseField name="fail_message" type="string | null">
  一句英文说明：发生了什么、该怎么做。可原样展示；程序逻辑请依据 `fail_reason`，因为措辞可能会变。
</ResponseField>
<ResponseField name="created_at" type="datetime" required />
<ResponseField name="updated_at" type="datetime | null" />
<ResponseField name="items" type="OrderItem[]" required>
  逐件商品明细。每件商品包含 `market_hash_name`、`price_usd`、`status`（`hold` | `delivering` | `delivered` | `returned`）、`tradable_at`、`return_reason`、`steam_trade_offer_id` 以及 `steam_trade_offer_finished_at`。
</ResponseField>

## 示例请求

```bash
curl https://csboard.com/v1/orders/ord_01J9Z3K8Q2 \
  -H "Authorization: Bearer csb_pub_..."
```

## 错误代码

| HTTP 状态码 | 代码 | 含义 |
|---|---|---|
| 401 | `missing_api_key` / `invalid_api_key` | API 密钥缺失或无效。 |
| 404 | `order_not_found` | 该 id 对应的订单不存在。 |
| 429 | `rate_limit_exceeded` | 请求过多。请按照 `Retry-After` 响应头中的秒数退避。 |
