orders 端点返回您的购买历史，按时间倒序排列，使用键集分页。可按时间窗口和状态过滤，然后通过将 `meta.next_cursor` 作为 `cursor` 传回，遍历更早的页面。每个订单都附带逐件商品明细及其交付状态。

**需要身份验证。** 请将密钥作为 `Authorization: Bearer csb_pub_...` 发送。

## 查询参数

<ParamField query="limit" type="integer" default="50">
  每页结果数。最小 `1`，最大 `100`。
</ParamField>

<ParamField query="start_unix_time" type="integer">
  仅返回在该 Unix 时间戳（秒）当时或之后创建的订单。
</ParamField>

<ParamField query="end_unix_time" type="integer">
  仅返回在该 Unix 时间戳（秒）当时或之前创建的订单。
</ParamField>

<ParamField query="status" type="string">
  按订单状态过滤。可选值：`completed`、`hold`、`delivering`、`pending`、`cancelled`、`failed` 之一。
</ParamField>

<ParamField query="cursor" type="string">
  来自上次响应中 `meta.next_cursor` 的键集游标。传入以获取下一页。
</ParamField>

    </ResponseField>
    <ResponseField name="charged_total_usd" type="number" required>

    <ResponseField name="delivery_deadline_at" type="datetime | null">

    </ResponseField>

    </ResponseField>

<a id="fail-reasons" />
## 订单失败的原因

状态为 `failed` 或 `cancelled` 的订单会用三个字段说明原因。其他任何状态下，这三个字段都为 `null`。

- `fail_reason` —— 用于程序分支判断的代码，取值见下表。
- `fail_side` —— 需要采取行动的一方：`recipient`、`seller`、`buyer` 或 `market`。
- `fail_message` —— 一句英文说明：发生了什么、该怎么做。可展示给用户；程序逻辑请依据 `fail_reason`。

| `fail_reason` | `fail_side` | 发生了什么、该怎么做 |
|---|---|---|
| `recipient_inventory_private` | `recipient` | 收货方的 Steam 库存未公开，因此无法发送交易。请将库存设为公开后重新购买。 |
| `recipient_inventory_full` | `recipient` | 收货方的 CS2 库存已满。请腾出空位后重新购买。 |
| `invalid_trade_url` | `recipient` | 交易链接无效，或其 token 已更改。请从 [steamcommunity.com/my/tradeoffers/privacy](https://steamcommunity.com/my/tradeoffers/privacy) 获取当前链接后重新购买。 |
| `recipient_cannot_trade` | `recipient` | 该账户目前无法交易：交易封禁、交易冷却或 Steam 令牌（Steam Guard）限制。在 Steam 解除限制之前，为该账户重新购买都会失败。 |
| `recipient_too_many_offers` | `recipient` | 收货方有过多待处理的交易报价。请先接受或拒绝它们，再重新购买。 |
| `offer_declined` | `recipient` | 收货方拒绝了交易报价。 |
| `offer_expired` | `recipient` | 交易报价未在规定时间内被接受。 |
| `seller_did_not_deliver` | `seller` | 卖家未按时发送物品。请购买其他挂单。 |
| `seller_cancelled` | `seller` | 卖家取消了出售（P2P）。请购买其他挂单。 |
| `rolled_back` | `seller` | 交付后，该交易在 Steam 中被撤回（P2P）。 |
| `cancelled_by_buyer` | `buyer` | 订单已按您的请求取消。 |
| `listing_gone` | `market` | 在购买完成之前，该挂单已在别处售出。请购买其他挂单。 |
| `market_unavailable` | `market` | 该挂单所在的市场暂时不可用。请稍后重试。 |
| `unavailable` | `market` | 物品无法交付，且没有更具体的原因。 |

该列表可能会扩充。遇到不认识的 `fail_reason` 时，请按 `unavailable` 处理。逐件商品的 `return_reason` 保持不变。

## 错误代码

| HTTP 状态码 | 代码 | 含义 |
|---|---|---|
| 401 | `missing_api_key` / `invalid_api_key` | API 密钥缺失或无效。 |
| 422 | `invalid_request` | 查询参数无效（例如 `limit` 超出范围）。 |
| 429 | `rate_limit_exceeded` | 请求过多。请按照 `Retry-After` 响应头中的秒数退避。 |
