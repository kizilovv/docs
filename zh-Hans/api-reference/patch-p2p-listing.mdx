---
title: "PATCH /v1/p2p/listings/{id} — 修改挂单价格"
sidebarTitle: "PATCH /p2p/listings/{id}"
description: "调整您在 CSBoard P2P 市场上一条在售挂单的价格。适用与发布时相同的价格下限。"
openapi: "PATCH /p2p/listings/{id}"
---

修改您某条 `active` 挂单的价格。以美分精度发送新的 `price_usd`，范围 `0.10` 到 `100000`。响应为更新后的挂单，其中 `commission_usd` 和 `seller_payout_usd` 已按新价格重新计算。

与发布时相同的价格下限同样适用，且无法通过确认绕过：低于我们对该物品市场价一半的价格会返回 `422 price_below_market`，并附带 `market_usd` 和 `floor_usd`。已售出或正在交易中的挂单无法再改价。

**需要身份验证。** 请将密钥作为 `Authorization: Bearer csb_pub_...` 发送。计入该密钥每分钟 30 次的 P2P 写操作限额。

## 示例请求

```bash
curl -X PATCH https://csboard.com/v1/p2p/listings/cm1xq8z4k0003ab12cd34ef56 \
  -H "Authorization: Bearer csb_pub_..." \
  -H "Content-Type: application/json" \
  -d '{ "price_usd": 11.50 }'
```

## 错误代码

| HTTP 状态码 | 代码 | 含义 |
|---|---|---|
| 400 | `invalid_request` | 请求体格式错误，或价格不在 `0.10`–`100000` 范围内或超过两位小数。 |
| 400 | `listing_not_active` | 该挂单已售出、正在交易中或已下架。 |
| 403 | `not_owner` | 该挂单属于其他账户。 |
| 403 | `account_banned` / `ip_not_allowed` | 账户已被封禁，或请求来自该密钥 IP 白名单之外的地址。 |
| 404 | `listing_not_found` | 不存在该 id 的挂单。 |
| 422 | `price_below_market` | 价格低于我们市场价的一半。参见 `market_usd` 和 `floor_usd`。 |
| 429 | `rate_limit_exceeded` | 本分钟内 P2P 写操作超过 30 次，或超过该密钥的通用限额。请等待 `Retry-After` 响应头中的秒数。 |
| 503 | `p2p_disabled` / `p2p_reprice_disabled` | P2P 市场或其改价功能目前已关闭。 |
