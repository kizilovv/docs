orders 端点允许您在单次原子请求中购买 1 到 10 件挂单。扣款将以执行**当时**的实时报价从您的 CSBoard 余额中划扣——而非您查询 `/v1/listings` 时看到的价格。为防止查询与下单之间的价格波动，请始终包含 `max_price_usd` 作为总价上限。该端点是幂等的：使用相同的 `Idempotency-Key` 重试会重放原始订单，而非产生重复扣款。

**需要身份验证。** 请将密钥作为 `Authorization: Bearer csb_pub_...` 发送。

**需要交易能力。** API 密钥必须启用购买功能。请在您的 CSBoard 个人资料中进行配置。

## 前置条件

下单前，请确保：

1. **启用交易的密钥**——必须在您的 CSBoard 个人资料设置中为该 API 密钥开启购买功能。
2. **已绑定的 Steam 账户与交易链接**——您的 CSBoard 账户必须已绑定 Steam 账户并配置有效的交易链接，以便商品可以交付。
3. **充足的余额**——您的 CSBoard 余额必须能够覆盖所有商品按实时价格的总成本。

## 请求头

<ParamField header="Idempotency-Key" type="string">
  可选，8–128 个字符（例如 UUID），用于标识本次下单尝试。如果您使用相同的键重试请求，服务器将返回 `200`、附带 `Idempotent-Replayed: true` 响应头以及原始订单响应，而不会执行第二次购买。若第一次请求仍在处理中，重试将返回 `409 idempotency_in_progress`。借此可在网络超时时安全重试而无重复扣款风险。
</ParamField>

## 请求体

<ParamField body="item_ids" type="string[]" required>
  1–10 个唯一的挂单 ID 数组。请从 `GET /v1/listings` 响应的 `id` 字段获取。每个 ID 在一次请求中只能出现一次。
</ParamField>

<ParamField body="max_price_usd" type="number">
  美元总价上限，将在执行时原子地强制执行。如果所有商品的实时总额超过该值，整个订单将以 `price_moved` 错误被拒绝，且不会扣款。**强烈建议使用**——若无此值，您将无任何超额扣款保护。
</ParamField>

<ParamField body="idempotency_key" type="string">
  `Idempotency-Key` 请求头的替代方案。如果两者都提供，则以请求头为准。请二选一使用，不要同时使用。
</ParamField>

<ParamField body="appId" default="730" type="integer">
  `item_ids` 所属的游戏：`730` = CS2，`570` = Dota 2，`252490` = Rust。不传则为 CS2。请使用您从 `GET /v1/listings` 读取这些 id 时所用的同一个 `appId`。查看 [`GET /v1/games`](/zh-Hans/api-reference/get-games) 中的 `tradable`，了解您的密钥可以在哪些游戏中购买。
</ParamField>

## 响应字段

新订单返回 **`201 Created`**。幂等重放返回 `200`，响应体相同。

<ResponseField name="order_id" type="string" required>
  本次订单的唯一标识符。将其传给 `GET /v1/orders/{id}` 以跟踪交付。
</ResponseField>

<ResponseField name="status" type="string" required>
  生成响应时订单的内部状态，例如 `paid` 或 `pending_delivery`。这不是 `GET /v1/orders` 中规范化的 `status` 取值——请在那里或通过 [Webhooks](/guides/webhooks) 跟踪订单。
</ResponseField>

<ResponseField name="currency" type="string" required>
  始终为 `USD`。
</ResponseField>

<ResponseField name="charged_total_usd" type="number" required>
  从您余额中扣除的总额，单位美元。
</ResponseField>

<ResponseField name="item_count" type="integer">
  订单中的商品数量。
</ResponseField>

<ResponseField name="items" type="object[]">
  每件购买的商品一条记录。

  <Expandable title="Item object">
    <ResponseField name="market_hash_name" type="string | null">
      商品的 Steam 市场哈希名称。
    </ResponseField>
    <ResponseField name="price_usd" type="number | null">
      该商品的扣款金额，单位美元。
    </ResponseField>
    <ResponseField name="status" type="string | null">
      商品的内部状态（如已设置）；刚购买后通常为 `null`。
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="delivery" type="string | null" required>
  已知时的交付方式：`instant`（机器人交付）或 `pending`（仍需卖家或供应商发起交易）。Dota 2 和 Rust 订单始终返回 `pending`。
</ResponseField>

<ResponseField name="expected_minutes" type="integer | null" required>
  可给出时的大致交付时间（分钟）。Dota 2 和 Rust 订单始终为 `null`。
</ResponseField>

<ResponseField name="created_at" type="datetime">
  订单创建时的 ISO 8601 时间戳。
</ResponseField>

<ResponseField name="updated_at" type="datetime | null">
  订单最后一次变更的 ISO 8601 时间戳。
</ResponseField>

## 示例请求

```bash
curl -X POST https://csboard.com/v1/orders \
  -H "Authorization: Bearer csb_pub_..." \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: 6f9c2b10-1a2b-4c3d-8e4f-5a6b7c8d9e0f" \
  -d '{
    "item_ids": ["itm_8841201", "itm_8841340"],
    "max_price_usd": 30.00
  }'
```

## 错误代码

| HTTP 状态码 | 代码 | 含义 |
|---|---|---|
| 400 | `invalid_request` | 请求体格式错误——`detail` 为按字段列出的错误。 |
| 400 | `unsupported_item` | 该 ID 无法通过 API 购买。请使用 `GET /v1/listings` 返回的 ID。 |
| 400 | `steam_account_required` | 您的 CSBoard 账户未绑定 Steam 账户或没有有效的交易链接。 |
| 400 | `cannot_mix_sources` / `one_external_per_order` | 这些商品不能放在同一订单中。请拆分订单。 |
| 400 | `unsupported_game` | 您的密钥不能在此 `appId` 中购买。`supported_app_ids` 列出了可以购买的游戏。 |
| 401 | `missing_api_key` / `invalid_api_key` | API 密钥缺失或无效。 |
| 402 | `insufficient_balance` | 余额不足。响应体包含 `required_usd` 和 `current_usd`。 |
| 402 | `kyc_required` | 本次购买需要先完成身份验证。响应体包含 `kyc_url`。 |
| 403 | `trading_not_enabled` | 该 API 密钥未启用购买功能。请在您的个人资料中启用。 |
| 403 | `account_restricted` | 账户受限。请联系客服。 |
| 409 | `price_moved` | 实时总额超过了 `max_price_usd`。订单被拒绝，未扣款。响应体包含 `quoted_max_usd`、`current_total_usd` 以及每件商品的实时价格。 |
| 409 | `item_unavailable` | 商品在您的订单到达前已售出。响应体可能包含 `unavailable_ids`。 |
| 409 | `idempotency_in_progress` | 使用该 `Idempotency-Key` 的请求仍在处理中。请稍候并用同一个键重试。 |
| 409 | `pending_trades_limit` | 收货方有过多未接受的 Steam 交易报价。上限见响应体中的 `limit`。 |
| 409 | `price_updating` / `concurrent_update` | 价格正在刷新，或并发订单抢先完成。未扣款——请重试。 |
| 429 | `rate_limit_exceeded` | 超过每分钟 250 个订单，或超过密钥的通用每分钟限制。请等待 `Retry-After` 响应头中的秒数。 |
| 500 | `order_failed` | 意外失败。重试前请先查看 `GET /v1/orders/info`——订单可能已经存在。 |
| 503 | `market_unavailable` | 其中一件商品所在的市场暂时不可用。未扣款。 |
| 504 | `upstream_timeout` | 结果未知。请使用相同的 `Idempotency-Key` 重新发送或轮询订单——切勿使用新的键。 |

<Warning>
  请始终在请求中包含 `max_price_usd`。实时市场上的价格可能在您查询 `/v1/listings` 到订单执行之间发生变化。若没有此上限，您的余额可能以高于预期的价格被扣除，且没有自动回滚机制。
</Warning>

<Note>
  通过 `hold` 交付的商品受 Steam 交易冻结约束。请查看原始挂单（来自 `GET /v1/listings`）上的 `tradable_at` 字段，了解被冻结的商品何时能在您的 Steam 库存中可交易。
</Note>

<Note>
  **Dota 2 和 Rust。** `appId` 为 `570` 或 `252490` 的订单会进入交付队列，并返回 `delivery: "pending"` 和 `expected_minutes: null`。请通过 [`GET /v1/orders/{id}`](/zh-Hans/api-reference/get-order) 跟踪。价格上限、余额检查和幂等性与 CS2 完全相同。
</Note>
